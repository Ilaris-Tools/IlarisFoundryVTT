Die wichtigsten Welteinstellungen für das Ilaris-System können über den letzten Tab in der Seitenleiste geöffnet werden. Diese Einstellungen können nur von der Spielleitung vorgenommen werden.

Grundsätzlich gilt: ⚠️ Führe einen Neustart von Foundry nach Änderung an den Settings durch!!

Zugriff

📍 Seitenleiste → Letzter Tab → Welteinstellungen

Benutzte Kompendien

Im Foundry-System werden grunsätzlich die Kompendien von Ilaris verwendet. Kompedien sind im Foundry-Kontext Sammlungen von Inhalten wie Charakteren, Gegenständen oder Regeln. Mit den folgenden Welteinstellungen kannst du steuern, welche Kompendien genutzt werden, wenn es um die Bestimmung von Waffeneigenschaften und Manövern gehen soll. Es ist vor allem ESSENTIELL WICHTIG, wenn man Hausregeln verwenden will. Denn nur mit der Wahl der richtigen Kompendien können die Charaktere richtig über die Sephrasto XMLs aktualisiertund importiert werden.

  • Fertigkeiten
  • Waffeneigenschaften
  • Talente
  • Manöver
  • Vorteile
  • Waffeneigenschaften
  • Abgeleitete Werte: Dieses Kompendium überschreibt bei Benutzung die Default-Werte der Abgeleiteten Werte wie WS,DH, etc. Jedoch nur standardmäßig Bestehende, keine frei erfundenen Neuen.

Wichtigste Einstellungen

🎯 Platzbedarf berücksichtigen

Hausregel aus Ilaris Advanced. Ohne Haken wird der Platzbedarf nicht angezeigt und in Berechnungen als 0 angenommen.

🎲 Echte Patzer und Krits

Für alle, die es bevorzugen, dass eine 1 immer ein Patzer ist und eine 20 immer ein kritischer Erfolg - unabhängig von der Schwierigkeit der Probe.

🎲 Umbennen von Triumph in Crit im Text

Einfach eine persönliche Präferenz der Entwickler für die Anzeige von Triumphen als Kritische Erfolge.

⚡ Energiekosten-Einstellung

Wenn aktiviert: Energiekosten können nur bei Unitatio-Vorteil oder nicht-numerischen Kosten manuell gesetzt werden.
Wenn deaktiviert: Energiekosten können immer manuell gesetzt werden.

⬡ Hexagonale Token-Bilder

Charakterbilder auf Hexfeld-Karten werden als Hexagone zugeschnitten. Verbessert die visuelle Darstellung auf Hexfeld-Gittern.

🔄 Charakter-Synchronisation Button ausblenden

Blendet den "Charakter mit Kompendium-Vorteilen Synchronisieren"-Button auf dem Heldensheet aus. Dieser Button ermöglicht es, Charakterdaten mit den Vorteilen,Waffen etc. aus den Kompendien abzugleichen. Ist für Charaktere gedacht, die nicht den XML-Import benutzen können, da sie in einer veralteten Sephrasto-Version erstellt wurden.

📚 Alternativ Fernkampf-Ausweichen Talent

Per Default wird beim Spielen mit Zielauswahl das standardmäßige Talent zum Ausweichen gegen Fernkampfangriff aus Ilaris verwendet. Wenn nur Fertigkeiten-Kompedien benutzt werden, die nicht über das Talent verfügen, kann hier ein alternatives Talent ausgewählt werden.

Automatisierung

🌤️ Scene-Umgebungseinstellungen verwenden

Wenn aktiviert: Licht und Wetter aus den Scene-Einstellungen werden automatisch in Fernkampf-Dialogen vorausgewählt.
Umgebungsbedingungen können direkt im Szene-Config Menü gesetzt werden.

🎯 Zielauswahl-System verwenden

Aktiviert Zielauswahl-Funktion und automatische Verteidigungsaufforderungen in Kampfdialogen:

  • Ermöglicht Auswahl von Zielen für Angriffe
  • Sendet automatisch Verteidigungsprompts an angegriffene Akteure
  • Bei Fernkampf: Ziele können mit Schilden oder durch Ausweichen mit Akrobatik verteidigen

💡 Tipp: Experimentiere mit den Automatisierungseinstellungen, um den Spielfluss für deine Gruppe zu optimieren!

🤖 LLM / KI-Einstellungen

Diese Einstellungen ermöglichen die automatische Generierung von Pre-Effects für Zaubersprüche, Liturgien und Anrufungen über eine KI-API (z.B. OpenAI, OpenRouter, DeepSeek oder ein lokales Ollama-Modell).

🔑 Konfiguration

Die folgenden drei Einstellungen müssen im Ilaris-Einstellungsdialog (Allgemein-Tab) gesetzt werden:

  • LLM API URL — Die Adresse des Chat-Completions-Endpunkts. Beispiele:
    OpenAI: https://api.openai.com/v1/chat/completions
    OpenRouter: https://openrouter.ai/api/v1/chat/completions
    DeepSeek: https://api.deepseek.com/v1/chat/completions
    Ollama (lokal): http://localhost:11434/v1/chat/completions
  • LLM API Key — Der API-Schlüssel. Wird als Passwort-Feld maskiert und nur im Browser der SL gespeichert — nie mit der Welt synchronisiert.
  • LLM Model — Das Modell. Beispiele: gpt-4o, deepseek-chat, openai/gpt-4o (OpenRouter), llama3 (Ollama).

🚀 Verwendung

  1. Öffne einen Zauber, eine Liturgie oder eine Anrufung im Item-Bogen.
  2. Scrolle zum Pre-Effects-Bereich.
  3. Klicke auf den 🤖 Generieren-Button (erscheint nur wenn API-URL und Key konfiguriert sind).
  4. Die KI analysiert den Zaubertext und generiert automatisch die passende Pre-Effect-Konfiguration.
  5. Der generierte Pre-Effect kann anschließend manuell angepasst werden.

⚠️ Wichtige Hinweise

  • Der API-Key wird ausschließlich lokal im Browser gespeichert und nie an andere Spieler:innen übertragen.
  • Die Einstellungen sind nur für die SL sichtbar — Spieler:innen sehen weder die Felder noch den Generieren-Button.
  • Ist kein API-Key oder keine URL konfiguriert, wird der Button ausgeblendet.
  • Die KI kann manchmal falsche Key-Pfade oder Schadenstypen vorschlagen — überprüfe das Ergebnis vor der Verwendung.
  • Jede Generation sendet eine Anfrage an die API — dies kann Kosten verursachen (abhängig vom Anbieter).
