Das Ilaris-System bietet umfangreiche Möglichkeiten zur Konfiguration von Items. Diese Übersicht zeigt die wichtigsten Item-Typen und ihre Konfigurationsmöglichkeiten.

✨ Vorteile

Zugriff

📦 Kompendium: "Vorteile" im Kompendium-Tab
➕ Hinzufügen: Drag & Drop auf Charakterbogen oder über "+" Button

📝 Konfigurationstipps für Vorteile

  • Prüfe Voraussetzungen im Vorteilstext: Bei Vorteile sind die Voraussetzungen nur zur Zierede da, ES WIRD NICHT geprüft ob eine Voraussetzungen erfüllt ist! Dafür ist Sephrasto zuständig.
  • Genauso wenig haben die EP-Kosten Auswirkung auf den Charakter in Foundry
  • Kampfstil-Vorteile:
    • Sephrasto Script Parameter: Steht in Foundry nur den Kampfstil-Vorteilen zur Verfügung. z.B.: modifyKampfstil('Beidhändiger Kampf', 1, 0, 0, 0), das Script macht genau das gleiche wie in Sephrasto auch, also modifiyKampfstil('Name(ist in foundry selbst eher unwichtig)',AT,VT,TP,RW,BE)
    • Die Stilbedingungen bestimmen, welche Voraussetzungen erfüllt sein müssen, damit der Kampfstil aktiv ist:
      • Leeres Feld: Kampfstil ist immer aktiv
      • Reittier: 'beritten' oder 'nicht beritten'
      • Trennung: Einzelne Bedingungen mit Komma trennen
        Beispiel: 'beritten, Schild'
      • Waffeneigenschaften: Direkt angeben
        Beispiele: 'Schild', 'Parierwaffe', 'Wendig'
      • Waffentypen:'Nahkampfwaffe' oder 'Fernkampfwaffe','einzelne Nahkampfwaffe' = nur eine Nahkampfwaffe,'zwei einhändige Nahkampfwaffen' = zwei Waffen
      • man kann Kampfstile auch auf Fertigkeiten einschränken: 'Fertigkeit <Name>'Beispiel: 'Fertigkeit Wurfwaffen'
    • Verfügbare Foundry-Scripts für Kampfstil-Modifikationen:
      • ignoreSideWeaponMalus(Eigenschaft)
        Ignoriert Erschwernisse für Nebenwaffe
        Parameter: Eigenschaft (optional)
        ignoreSideWeaponMalus('Wendig')
      • affectsRangedWeaponOnly()
        Modifier wirken nur auf Fernkampfwaffen: in Sephrasto und ohne dieses Foundry-Script wirken sich die Modifier von modifiyKampfstil nur auf Nahkampfwaffen aus. Dieses Script bewirkt, dass sich ALLE Modifier nur auf Fernkampfwaffen auswirken. Damit ist es möglich auch Fernkampfstile zu haben.
        Keine zusätzlichen Parameter
        affectsRangedWeaponOnly()
      • ignoreMountedRangePenalty()
        Ignoriert Fernkampf-Malus beim Reiten
        Keine zusätzlichen Parameter
        ignoreMountedRangePenalty()
      • manoverAusgleich(Wert)
        Setzt Manöverausgleich für Kampfstil: Deckt für Ilaris zum Beispiel den Vorteil von Parierwaffenkampf ab. Kommt erst im Kampfdialog zum Tragen und nur wenn auch Manöver ausgewählt sind. Im Script kann noch ein false mit gegeben werden (per default benutzt das Script true), dieser Parameter bewirkt, dass sich die Manövererleichterung auf alle Manöver auswirkt und nicht nur Basis-Manöver.
        Parameter: Wert = Manöverausgleichwert (Zahl), Auswirkung auf alle Manöver/Basis-Manöver: true/false (default ist true)
        manoverAusgleich(2)
      ⚠️ Mehrere Methoden mit Semikolon trennen
  • Vorteile können neben statischen Foundry-Änderungen auch kontextabhängige Ilaris-Modifikatoren besitzen. Bei Fertigkeitsproben wählst du die Situation im Dropdown; im Dialog für übernatürliche Fertigkeiten bestätigst du passende, von Spielleitung und Spieler:innen festgelegte Bedingungen. Der Bonus und seine Quelle sind anschließend immer in der Probenzusammenfassung sichtbar. Wichtig: Foundry erkennt weder Orte, Ziele, Ressourcen noch gewählte Zaubermodifikationen automatisch. Nicht als feste Probenmodifikation ausdrückbare Folgen – etwa Patzerregeln, Informationsgrade oder Regeneration – bleiben manuell.

⚔️ Manöver (Manöver)

Zugriff

Manöver stehen einem Actor (Helden und Kreaturen) automatisch im Kampfdialog zur Verfügung, wenn die Voraussetzungen dafür erfüllt sind! Kreaturen ignorieren die Voraussetzungen für Übernatürliche Manöver (in Sephrasto ist das IMMER eine Tradition oder Zauberer). Außerdem kommen die übernatürlichen Vorteile WIE in Sephrasto auch mit dem Zusatz L/M vor, falls Dopplungen bestehen zb. Kosten Sparen!

Manöver-Kategorien

In Foundry kommen die Manöver in folgenden Kategorien vor, die sich jeweils an den Kategorien aus Sephrasto anlehnen, mit dem Zusatz von Verteidigungsmanövern:

  • Nahkampfmanöver
  • Fernkampfmanöver
  • Magische Manöver
  • Liturgische Manöver
  • AnrufungsManöver
  • Verteidigungsmanöver

📝 Konfigurationstipps für Manöver

  • Manöver haben oft spezifische Voraussetzungen (Vorteile, Waffeneigenschaften): Es MUSS auf die korrekte Schreibweise geachtet werden, sonst steht das Manöver möglicherweise nicht zur Verfügung!
  • Für die Automatisierung von Manövern können Manöver-Modifikationen verwendet werden, diese funktionieren wie folgt:
    • Input: Manöver haben können eine von 3 Inputmöglichkeiten haben. Entweder ein Inputfeld für Zahlen (mit min und max, max leer lassen, bedeutet, dass man keine obere Grenze hat), eine Checkbox oder ein Dropdown-Menü mit den Trefferzonen.
    • Modifikatoren, bestimmen wie das Manöver beim Auswählen verhalten soll:
      • Modifikatortyp, gibt an was auf welchen Stat sich das Manöver auswirkt, zB. kann mit 'Angriff,Fernkampf,Übernatürliche Fertigkeit' der 'Angriffs'-Probenwert beeinflusst werden. Die folgenden Typen haben eine Implementierung im System:
        • Angriff,Fernkampf,Übernatürliche Fertigkeit: Angriff-Probenwert
        • Schaden: TP für Nahkampfangriffe und Fernkampfangriffe, hat keine Auswirkung auf Übernatürliche Talente
        • Verteidigung: Wirkt nur auf den VT-Wert bei Nahkampfangriffen
        • Resource für Zauber/Liturgie: beeinflusst die jeweilige Energie beim Einsatz von übernatürlichen Talenten
        • Waffenschaden: Speziell ist hier Waffenschaden gemeint zB. für Hammerschlag
        • Kein Schaden: Lässt das Manöver 0 Schaden anrichten und macht andere ähnliche Manöver nicht selektierbar
        • Spezialeffekt: kann bei allen Manövern verwendet werden und gibt im Chat einfach nur Text aus, was das Manöver spezielles macht. ZB hat das Manöver Rüstungsbrecher den Spezialeffekt, dass es Rüstung ignoriert. Was dann im Chat so ausgegeben wird.

      Allgemein finden sich in den Manövern wohl alle möglichen Kombinationen von Input und Modifikatoren wieder. Falls man selbst eines erstellt, kann man sich hier an den Vorhandenen orientieren. Beim XML-Import von Sephrasto für Hausregeln werden viele Modifikationen schon automatisch gesetzt, das ganze sollte aber auf jeden Fall auf seine Richtigkeit überprüft werden, da der Importer nur rudimentär bzw klassisch über Regex an das Ganze herangeht.

    • Operatoren umfassen: Addieren, Subtrahieren, Multiplizieren und Dividieren. Punkt wird vor Strich verrechnet!
    • Target: In diesem Feld kann man den Key eines Wertes im System des Actors angeben, also zb actor.system.abgeleitete.be, um den Wert für Behinderung zu bekommen. Dieser Wert wird dann entsprechend mit dem jeweiligen Operator als Modifikator verwendet
    • Die Checkbox ganz am Ende "Wird von Input beeinflusst", ist nur für das Inputfeld mit Zahlen wichtig und gibt an, dass der Modifikator mit der Zahl im Inputfeld multipliziert wird.
  • Im Kampfdialog können verfügbare Manöver direkt ausgewählt werden

Waffeneigenschaften

📦 Kompendium: "Waffeneigenschaften"

Wichtige Punkte für Waffeneigenschaften

Waffeneigenschaften können in Foundry individuell gestaltet werden. Hier sind einige Eckpunkte für die Erstellung.

Kategorie, gibt allgemein vor, um welche Art von Eigenschaft es sich handelt. Zur Zeit gibt es die folgenden Kategorien:

  • Modifikator: Damit kann die Waffe direkt noch mit einer erhöhten Patzer/Crit Chance oder einem Wert im System des Actors modifiziert werden, der Wert wird hier in der Formel abgerundet Wert/4 verwendet, dadurch lässt sich zb Kopflastig über @actor.system.attribute.KK.wert abdecken.
  • Führung: Hierunter fallen zb die Waffeneigenschaften 'Zweihändig' oder 'Schwer', also Waffeneigenschaften die je nach nicht sachgemäßer Führung bestimmte Auswirkungen haben. Hier kann auch gesetzt werden ob eine Waffe 'kein Malus als Nebenwaffe' hat oder ein Reittier erfordert oder nur ohne Reittier geführt werden kann.
  • Akteur-Modifikator: Hiermit kann die Waffeneigenschaft direkt einen dieser Werte auf dem Actor modifizieren oder setzen BE,GS,INI. Damit kann man zum Beispiel von einem Reittier die GS des Actors auf einen neuen Wert setzen oder weiter modifizeren.
  • Ziel-Effekt: noch nicht implementiert!
  • Passiv: Ist einfach nur eine Passive Waffeneigenschaft wie Schild oder Parierwaffe, die an sich keine direkten Auswirkungen auf die Waffe oder den Acotr haben
