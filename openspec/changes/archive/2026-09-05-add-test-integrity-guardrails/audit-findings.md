## Summary

- **VERSTOSS: 5 findings (F1–F4)** — 6 `waitForTimeout` calls in 5 E2E files, all violating the existing `e2e-testing` spec ("SHALL NOT use fixed-duration waitForTimeout"). Added by PR #496 (2×) and loose hardening commits (4×).
- **VERDACHT: 3 findings (F5–F7)** — conditional `test.skip` (environment-data dependent), 2 system-internal `jest.mock`s (boundary mocks with drift risk).
- **LEGIT: 5 findings (F8–F12)** — rewrites strengthen coverage, intentional behavior-change updates, moved-not-removed assertions, predicate waits.
- **UNKLAR / NOTE: 2 (F13, F14)**.
- No unit-test weakening or blind snapshot updates were found. `playwright.config.ts` unchanged (no retries changes).
